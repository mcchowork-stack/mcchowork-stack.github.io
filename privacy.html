시행일: 2026-10-01

수집하는 정보

autorim-chat은 YouTube Data API의 읽기 전용 권한(youtube.readonly)으로 방송자 본인 채널의 진행 중인 라이브 방송 정보와, 그 방송의 라이브 채팅 메시지(작성자 표시 이름, 메시지 내용, 작성 시각)만 읽습니다.

이용 목적

읽은 채팅은 방송 중 AI 플레이어가 시청자 의견을 참고하고, 답변을 방송 화면에 표시하는 데에만 사용합니다.

보관과 공유

정보는 방송자 개인 PC에만 저장되며, 판매하거나 제3자에게 제공하지 않습니다. 광고나 분석 목적으로 사용하지 않습니다. 방송자는 Google 계정 설정(myaccount.google.com/permissions)에서 언제든 앱 권한을 철회할 수 있습니다.

Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

English summary

autorim-chat uses the read-only YouTube scope to read the live chat (display name, message text, timestamp) of the streamer's own active broadcast. The data stays on the streamer's PC, is used only to let the AI player consider viewer feedback and show replies on the stream, and is never sold or shared. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
